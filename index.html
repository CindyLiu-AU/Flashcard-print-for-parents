如何获取令牌
  1. 前往 github.com → Settings（右上角头像）
  2. 向下滚动 → Developer settings
  3. Personal access tokens → Tokens (classic)
  4. 点击 Generate new token (classic)
  5. Note：随意填写，Expiration：选 No expiration
  6. 勾选 repo 复选框
  7. 点击 Generate token → 复制令牌
